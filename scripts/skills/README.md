# FactorHub Claude Code Skills

7个可运行的因子分析技能脚本集合，用于快速调用FactorHub API进行因子研究。

## 前置要求

1. **API服务运行**: 确保FactorHub API服务运行在 `http://localhost:8000`

   ```bash
   cd /home/user/FactorHub
   python -m uvicorn backend.api.main:app --host 0.0.0.0 --port 8000 --reload
   ```

2. **依赖**: requests库（通常已包含）

   ```bash
   pip install requests
   ```

## 高级用法

### 自定义API地址

所有脚本都支持 `--api-url` 参数：

```bash
python factor_analyze.py 000001 "RSI(14)" --api-url http://192.168.1.100:8000/api
```

### 获取帮助

```bash
python <skill_name>.py --help
```

### 日期格式

所有日期都使用 `YYYY-MM-DD` 格式：
- `2023-01-01` ✅
- `2023-1-1` ❌
- `2023/01/01` ❌

### 因子表达式

支持所有FactorHub支持的因子表达式：
- 简单: `close`, `open`, `high`, `low`, `volume`
- 函数: `SMA(close, 20)`, `RSI(close, 14)`, `MACD(close)`
- 复杂: `(close - SMA(close, 20)) / SMA(close, 20)`
- 多步: `SLOPE(SMA(close, 20), 5)`

**验证公式的有效性**:
```bash
python validate_formula.py "您的公式" 000001
```

## 常见问题

### Q: API连接失败

**A**: 确保API服务运行在 `http://localhost:8000`

```bash
# 启动API服务
cd /home/user/FactorHub
python -m uvicorn backend.api.main:app --host 0.0.0.0 --port 8000
```

### Q: 日期范围无效

**A**: 确保开始日期早于结束日期，都使用 `YYYY-MM-DD` 格式

```bash
# ✅ 正确
python factor_analyze.py 000001 "RSI(14)" 2023-01-01 2024-12-31

# ❌ 错误
python factor_analyze.py 000001 "RSI(14)" 2024-12-31 2023-01-01
```

### Q: 因子公式出错

**A**: 使用 `validate_formula.py` 验证公式有效性

```bash
python validate_formula.py "(close - SMA(close, 20)) / SMA(close, 20)" 000001
```

### Q: 任务超时

**A**: 因子挖掘和优化可能需要几分钟，请耐心等待。可以增加 `--api-url` 确保连接正常。

## 集成到Claude Code

### 方式1: 命令快捷方式

在Claude Code中创建快捷命令：

```bash
# 在项目根目录创建 .claude/commands.json
{
  "analyze": "python scripts/skills/factor_analyze.py",
  "backtest": "python scripts/skills/backtest_factor.py",
  "compare": "python scripts/skills/compare_strategies.py",
  "mine": "python scripts/skills/mine_factors.py"
}
```

### 方式2: 直接调用

在Claude Code Prompt中：

```
请使用以下命令分析000001的RSI(14)因子:
python scripts/skills/factor_analyze.py 000001 "RSI(close, 14)" 2023-01-01 2024-12-31
```

### 方式3: 批量任务

创建批量脚本：

```bash
#!/bin/bash
# batch_analyze.sh

STOCKS=("000001" "600519" "000858")
FACTORS=("RSI(close,14)" "close/SMA(close,20)" "momentum_20")

for stock in "${STOCKS[@]}"; do
  for factor in "${FACTORS[@]}"; do
    echo "分析 $stock - $factor"
    python scripts/skills/factor_analyze.py "$stock" "$factor" 2023-01-01 2024-12-31
  done
done
```

## 工作流示例

### 完整因子研究流程 (5分钟)

```bash
# Step 1: 验证因子公式
python validate_formula.py "(close - SMA(close, 20)) / SMA(close, 20)" 000001

# Step 2: 分析因子特性 (IC/IR)
python factor_analyze.py 000001 "(close - SMA(close, 20)) / SMA(close, 20)" 2023-01-01 2024-12-31

# Step 3: 历史回测
python backtest_factor.py 000001 "(close - SMA(close, 20)) / SMA(close, 20)" 2023-01-01 2024-12-31

# Step 4: 输出报告
# 以上命令的输出已包含详细的分析报告
```

### 多策略对比流程 (3分钟)

```bash
# 对比3个策略
python compare_strategies.py 000001 \
  "RSI(close,14)" \
  "close/SMA(close,20)" \
  "momentum_20" \
  2023-01-01 2024-12-31
```

### 因子优化流程 (10分钟)

```bash
# Step 1: 挖掘新因子
python mine_factors.py 000001 \
  --base "RSI(close,14),close/SMA(close,20)" \
  --generations 10 \
  2023-01-01 2024-12-31

# Step 2: 优化组合权重
python portfolio_optimize.py 000001 \
  "factor1" "factor2" "factor3" \
  2023-01-01 2024-12-31 \
  --method max_sharpe
```
